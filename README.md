# Yono Hub V2.0 — Modern Mobile Game & Rummy APK Download Platform

A professional, modern, fast, and fully responsive mobile gaming download platform built with **React 19**, **Vite 8**, **Tailwind CSS v4**, and **Lucide Icons**.

---

## 🚀 Key Features

- **70 Verified Mobile Games & Rummy Apps**: Fast, direct APK downloads with one-click access.
- **Categorization**:
  - **All Games**: Complete 70-game repository.
  - **Popular Games**: Top-rated, trending games.
  - **New Release**: Newly added, recent releases.
  - **Rummy**: Dedicated Rummy and card game collection.
- **Search & Auto-Suggestions**: Real-time filtering by game name, developer, and tags.
- **Floating Telegram Community**: Instant link to join official Telegram channel.
- **SEO & Google Search Ready**: Pre-configured JSON-LD structured data, Open Graph tags, XML sitemap (`sitemap.xml`), and `robots.txt`.
- **18+ Responsible Gaming Disclaimer**: Clearly visible in the About section.
- **Mobile-First Responsive Layout**: Smooth horizontal navigation tabs, touch-friendly buttons, and zero clutter.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS v4 + Vanilla CSS Variables
- **Icons**: Lucide React
- **Hosting**: GitHub Pages / Static Hosting

---

## 💻 Development & Build

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
